# 统一清理工具使用说明

## 概述

统一清理工具将原来的 `clear_database.py` 和 `cleanup_temp_files.py` 合并为一个功能完整的图形界面清理工具，提供模态框选择需要清理的内容，一次性完成全部清理操作。

## 功能特性

- 🖥️ **图形界面**：友好的GUI界面，支持模态框选择
- 🗂️ **多种清理选项**：支持文件、目录、数据库等多种清理类型
- 📊 **实时进度**：实时显示清理进度和日志
- ⚙️ **灵活配置**：可选择具体的清理内容
- 🛡️ **安全确认**：清理前显示确认对话框
- 📝 **详细日志**：记录所有清理操作的详细信息

## 清理选项

| 选项 | 描述 | 默认选择 |
|------|------|----------|
| 临时上传文件 | 清理 `temp_uploads` 目录 | ✅ |
| 临时文档文件 | 清理 `temp_word` 目录 | ✅ |
| 上传文件 | 清理 `uploads` 目录 | ❌ |
| PDF缓存文件 | 清理 `temp_pdf_cache` 目录 | ✅ |
| 根目录临时文件 | 清理根目录下的非必要文件 | ✅ |
| 数据库内容 | 清空数据库（保留表结构） | ❌ |
| 日志文件 | 清理项目日志文件 | ✅ |

## 使用方法

### 方法一：使用批处理文件（推荐）
双击运行 `启动清理工具.bat`

### 方法二：使用Python脚本
```bash
python cleanup_tool.py
```

### 方法三：直接运行主程序
```bash
python unified_cleanup_tool.py
```

## 界面说明

1. **选择清理内容**：勾选需要清理的项目
2. **快捷按钮**：
   - **全选**：选择所有清理选项
   - **全不选**：取消所有选择
   - **推荐选择**：选择推荐的清理选项
3. **进度显示**：显示当前清理进度和状态
4. **日志区域**：实时显示清理过程和结果
5. **操作按钮**：
   - **开始清理**：执行选中的清理操作
   - **清空日志**：清除日志显示
   - **退出**：关闭程序

## 安全保护

- ✅ **配置文件保护**：自动保护重要配置文件
- ✅ **确认对话框**：清理前显示确认信息
- ✅ **操作日志**：记录所有操作便于追踪
- ✅ **错误处理**：优雅处理清理过程中的错误

## 保护的配置文件

以下文件在根目录临时文件清理时会被保护：
- `config.json`
- `settings.json`
- `runtime_config.json`
- `runtime_settings.json`
- `MinerU_API_token.txt`
- `pyproject.toml`
- `setup.cfg`
- `.pylintrc`

## 注意事项

1. **备份重要数据**：清理前请确保重要数据已备份
2. **关闭相关程序**：清理前建议关闭正在使用文件的程序
3. **数据库清理**：数据库清理会删除所有数据，请谨慎操作
4. **权限要求**：确保程序有足够权限删除文件

## 技术特性

- **跨平台兼容**：支持Windows、Linux、macOS

## 故障排除

### 常见问题

**Q: 程序无法启动**
A: 请确保在项目根目录运行，且安装了所有依赖

**Q: 数据库清理失败**
A: 请确保数据库文件未被其他程序占用

**Q: 文件删除失败**
A: 请检查文件权限和是否被其他程序使用

**Q: 界面显示异常**
A: 请确保安装了 tkinter 库
