# 评标系统流程图

## 1. 系统架构概述

```mermaid
graph TB
    A[用户界面] --> B[Flask Web应用]
    B --> C[路由层]
    C --> D[控制器层]
    D --> E[业务逻辑层]
    E --> F[数据访问层]
    F --> G[SQLite数据库]
    E --> H[AI分析模块]
    E --> I[PDF处理模块]
    E --> J[价格计算模块]
```

## 2. 项目创建流程

```mermaid
graph TD
    A[用户创建项目] --> B[前端发送创建请求]
    B --> C[POST /api/projects]
    C --> D[ProjectController.create_project]
    D --> E[验证输入参数]
    E --> F[生成项目代码]
    F --> G[保存招标文件]
    G --> H[创建TenderProject记录]
    H --> I[返回项目信息]
    I --> J[前端显示项目列表]
```

## 3. 投标文件上传流程

```mermaid
graph TD
    A[用户上传投标文件] --> B[前端发送上传请求]
    B --> C[POST /api/projects/project_id/bids/upload]
    C --> D[FileController.upload_bid_files]
    D --> E[验证文件类型和大小]
    E --> F[保存文件到uploads目录]
    F --> G[创建BidDocument记录]
    G --> H[返回上传结果]
    H --> I[前端显示投标文件列表]
```

## 4. 投标人名称确认流程

```mermaid
graph TD
    A[用户查看投标文件列表] --> B[GET /api/projects/project_id/bidders]
    B --> C[ProjectController.list_project_bidders]
    C --> D[查询BidDocument记录]
    D --> E[返回投标文件和当前名称]
    E --> F[用户编辑投标人名称]
    F --> G[PATCH /api/bids/bid_id/name]
    G --> H[ProjectController.update_bidder_name]
    H --> I[更新BidDocument和AnalysisResult中的名称]
    I --> J[返回更新结果]
```

## 5. 项目分析启动流程

```mermaid
graph TD
    A[用户启动分析] --> B[POST /api/projects/project_id/start-analysis]
    B --> C[AnalysisController.start_analysis]
    C --> D[验证项目和投标文件]
    D --> E[更新投标人名称]
    E --> F[创建AnalysisManager实例]
    F --> G[启动后台分析线程]
    G --> H[更新项目状态为processing]
    H --> I[返回分析启动结果]
```

## 6. 核心分析流程

```mermaid
graph TD
    A[AnalysisManager.run_analysis_and_calculate_prices] --> B[initialize_project_analysis]
    B --> C[提取评分规则]
    C --> D[保存评分规则到数据库]
    D --> E[循环处理每个投标文件]
    E --> F[analysis_task]
    F --> G[提取投标人名称和内容分析]
    G --> H[保存分析结果]
    H --> I[使用统一提取器提取所有投标人信息]
    I --> J[遍历output目录提取投标人名称和价格]
    J --> K[保存到数据库]
    K --> L[创建投标人价格数组]
    L --> M[获取价格评分规则]
    M --> N[构造AI prompt]
    N --> O[调用AI计算价格分]
    O --> P[解析AI响应]
    P --> Q[验证和修正价格分]
    Q --> R[保存价格分到数据库]
    R --> S[更新项目状态]
```

## 7. 单个投标文件分析流程

```mermaid
graph TD
    A[analysis_task] --> B[获取BidDocument]
    B --> C[初始化投标人名称]
    C --> D[更新处理状态]
    D --> E[PDF处理和投标人名称提取]
    E --> F[创建IntelligentBidAnalyzer]
    F --> G[analyze_bidding_document]
    G --> H[处理分析结果]
    H --> I[保存AnalysisResult]
    I --> J[更新处理状态]
```

## 8. 投标人名称提取流程

```mermaid
graph TD
    A[PDFProcessor.process_pdf_to_md] --> B[使用MinerU处理PDF]
    B --> C[生成MD文件]
    C --> D[extract_bidder_name_from_file]
    D --> E[在特殊章节中搜索]
    E --> F[使用正则表达式提取]
    F --> G[从Markdown格式提取]
    G --> H[使用AI提取]
    H --> I[过滤和验证名称]
    I --> J[返回投标人名称]
```

## 9. 智能投标分析流程（排除价格规则）

```mermaid
graph TD
    A[analyze_bidding_document] --> B[加载评分规则]
    B --> C[分离规则类型]
    C --> D[排除价格规则]
    D --> E[获取定量规则 is_price_criteria=false Child_max_score>0]
    E --> F[获取定性规则 is_price_criteria=false Child_max_score=0或null]
    F --> G[获取投标文件内容]
    G --> H[检查否决项]
    H --> I{否决项通过?}
    I -->|否| J[标记不合格并返回]
    I -->|是| K[分析定量规则]
    K --> L[分析定性规则]
    L --> M[计算除价格外的总分]
    M --> N[保存分析结果]
    N --> O[返回分析结果]
```

## 10. 价格规则特殊处理流程

```mermaid
graph TD
    A[价格规则处理] --> B[规则标识]
    B --> C[is_price_criteria=true]
    C --> D[独立存储]
    D --> E[包含price_formula字段]
    E --> F[价格计算阶段处理]
    F --> G[价格计算工作流]
    G --> H[价格分计算器]
    H --> I[AI价格分计算]
    I --> J[默认价格分计算]
    J --> K[更新价格分和总分]
```

## 11. 统一提取器流程

```mermaid
graph TD
    A[UnifiedExtractor.extract_all_bidders_info] --> B[获取项目所有投标文件]
    B --> C[循环处理每个投标文件]
    C --> D[extract_bidder_info]
    D --> E[extract_bidder_name]
    E --> F[extract_bidder_name_from_file]
    D --> G[extract_bid_price]
    G --> H[优先从MD文件提取价格]
    H --> I[使用MDPriceExtractor直接提取]
    I --> J[如果未提取到则使用PriceManager]
    J --> K[保存到数据库]
    K --> L[返回投标人信息列表]
```


## 15. 规则处理分类流程

```mermaid
graph TD
    A[评分规则处理] --> B[规则分类]
    B --> C{是否为价格规则?}
    C -->|是| D[价格规则特殊处理]
    D --> E[is_price_criteria=true]
    E --> F[独立工作流处理]
    F --> G[价格分计算器]
    G --> H[AI价格分计算]
    C -->|否| I{是否有分数?}
    I -->|是| J[定量规则处理]
    J --> K[Child_max_score>0]
    K --> L[逐条AI分析]
    I -->|否| M[定性规则处理]
    M --> N[Child_max_score=0或null]
    N --> O[组合AI分析]
```

## 16. 数据库实体关系图

```mermaid
erDiagram
    TenderProject ||--o{ BidDocument : contains
    TenderProject ||--o{ AnalysisResult : contains
    TenderProject ||--o{ ScoringRule : contains
    TenderProject ||--o{ ProjectAuditLog : contains
    BidDocument ||--|| AnalysisResult : has
    AnalysisResult ||--o{ ScoreModificationHistory : contains
    
    TenderProject {
        int id PK
        string project_code
        string name
        string description
        string tender_file_path
        json scoring_rules_summary
        datetime created_at
        string status
        datetime analysis_start_time
        datetime analysis_end_time
    }
    
    BidDocument {
        int id PK
        int project_id FK
        string bidder_name
        string file_path
        string original_filename
        int file_size
        string processing_status
        string error_message
        int progress_total_rules
        int progress_completed_rules
        string progress_current_rule
        string partial_analysis_results
        string detailed_progress_info
        string processing_phase
        string failed_pages_info
        int price_extraction_attempts
        string price_extraction_error
        boolean price_extracted
        int ocr_retry_count
        datetime upload_time
    }
    
    AnalysisResult {
        int id PK
        int project_id FK
        int bid_document_id FK
        string bidder_name
        float total_score
        float price_score
        float extracted_price
        json detailed_scores
        json dynamic_scores
        string analysis_summary
        datetime analyzed_at
        string scoring_method
        string ai_model
        boolean is_modified
        json original_scores
        int modification_count
        datetime last_modified_at
        string last_modified_by
    }
    
    ScoringRule {
        int id PK
        int project_id FK
        string Parent_Item_Name
        int Parent_max_score
        string Child_Item_Name
        int Child_max_score
        string description
        boolean is_veto
        boolean is_price_criteria
        string price_formula
    }
    
    ScoreModificationHistory {
        int id PK
        int analysis_result_id FK
        string criteria_name
        float original_score
        float new_score
        string original_reason
        string new_reason
        string modification_type
        string modified_by
        datetime modified_at
        string modification_reason
        string approval_status
        string approved_by
        datetime approved_at
    }
    
    ProjectAuditLog {
        int id PK
        int project_id FK
        string operation_type
        json operation_details
        string operator
        datetime operation_time
        string ip_address
        string user_agent
    }
```
